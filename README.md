
# 🎮 Game Committee

Welcome to the **Game Committee** repository! 🚀

This repository is the central hub for our Game Committee projects, resources, and development work.

We use **Godot Engine** as our main game development engine because it is **free, open-source, and community-driven**, making it a great choice for learning, experimenting, and building games without relying on proprietary software.

## 🛠️ What We Use

* 🎮 **Godot Engine** — Our primary game development engine
* 💻 **GDScript** — The main scripting language used with Godot
* 🌐 **Git & GitHub** — Version control and collaboration
* 🎨 **Open-source tools & resources** — Supporting our development workflow

## 📂 Repository Contents

This repository may include:

* Game projects and prototypes
* Learning materials and resources
* Committee tasks and assignments
* Scripts and development assets
* Documentation and project notes

## 🌱 Why Godot?

We believe in learning and building with **open-source technologies**. Godot provides a powerful and flexible environment for game development while keeping the tools accessible to everyone.

By using Godot, we aim to encourage:

* Open-source development
* Collaboration and knowledge sharing
* Creative experimentation
* Practical game development skills

## 🤝 Contributing

Members of the Game Committee are encouraged to contribute, experiment, share ideas, and help improve our projects.

Let's learn, build, and create games together! 🎮✨
